LLM Tweaker Builder - Windows launcher

Double-click:

  Run LLM Tweaker Builder.bat

The launcher starts the local builder dashboard from nanochat-master.

Requirements:

  - Python available as "python"
  - Local Python packages already installed in nanochat-master\.venv or system site-packages
  - Optional helper models can be placed in nanochat-master\assistant_models or nanochat-master\models

Default dashboard:

  http://localhost:8000

If the window reports missing packages, install the project dependencies in nanochat-master before launching again.
